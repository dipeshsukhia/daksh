# Daksh Champaneria — Personal Portfolio

A simple, multi-page student portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. The site does not need a build step or package installation.

## Pages

- Home
- About Me
- My Skills
- My Achievements
- My Goals
- Contact

The shared stylesheet and JavaScript are in `assets/css/` and `assets/js/`. Photos used by the site are in `assets/image/`.
